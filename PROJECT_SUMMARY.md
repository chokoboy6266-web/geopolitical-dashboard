# Project Summary: Geopolitical Dashboard

## Overview
The **GeoStrat Antigravity Engine** is a high-performance geopolitical intelligence dashboard designed to provide real-time situational awareness of global risks. It filters "noise" from global events and presents "signals" that have significant strategic, economic, or political implications.

## Core Objective
To provide a visual and analytical layer for understanding complex global events, allowing users to quickly identify high-risk areas and understand the deeper context (second-order impacts, historical background, etc.) of geopolitical developments.

## Technical Stack
- **Frontend**: React 18, TypeScript, Vite
- **Visualization**: `react-globe.gl` (Three.js based 3D globe)
- **Styling**: Vanilla CSS with a focus on premium, dark-mode aesthetics.
- **Data Layer**: Mocked AI service (`aiService.ts`) simulating real-time signal processing.

## Key Components

### 1. Interactive 3D Globe (`GeoMap.tsx` / `Dashboard.tsx`)
- Uses high-resolution Natural Earth textures (Blue Marble, Topology).
- Dynamic point markers for geopolitical signals.
- Interactive "Deep Zoom" functionality to focus on specific regions when a signal is selected.
- Atmospheric rendering and night-sky backgrounds for a premium feel.

### 2. Signal Intelligence Layer (`aiService.ts`)
- Processes raw data into actionable "Signals".
- **Risk Scoring**: 1-10 scale of strategic impact.
- **Intelligence Metadata**: Confidence scores, "What Changed", and "Why It Matters".
- **Impact Analysis**: Categorizes second-order effects into Economic, Political, and Strategic buckets.

### 3. Intelligence Side Panel (`SidePanel.tsx`)
- Displays detailed analysis of the selected signal.
- Lists all active signals for quick navigation.
- Includes historical context and "What to Watch" indicators for future developments.

### 4. Voices Layer & Perspectives (`SignalCard.tsx`)
- **Analytical Lenses**: Provides Strategic, Economic, and Risk perspectives for every signal.
- **Key Takeaways**: Concise, neutral conclusions on what truly matters.
- **External Commentary**: Integration of relevant public posts (e.g., from X) with direct source links.
- **Toggle Control**: Global visibility control for the external commentary layer.
